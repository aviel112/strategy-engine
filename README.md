# מנוע האסטרטגיה — ממי פרודקשיין

> **להפעלה ראשונה: [SETUP.md](SETUP.md)** — 3 שלבים, 5 דקות.

## אבחון שיווקי לעסק

אתר לכידת לידים שמעביר בעל עסק מסע של 25 שאלות ומחזיר לו תוכנית שיווק
מותאמת: מיצוב, פלטפורמות, תמהיל תוכן, קצב, משפך ומספרים — ובסוף מוביל לפגישה.

## מבנה

```
index.html          כל החוויה — שאלון, מנוע כללים, gate, דוח
assets/             עוגני התמונות (anchor-1..4.jpg) — אופציונלי
ai-proxy/           שרת Node שמלטש את הטקסטים האישיים דרך Claude
```

## הזרימה

1. **פתיח** — הבטחה + 4 נקודות ערך
2. **25 שאלות ב-7 שלבים** — מי אני → למי אני פונה → הסיפור והערכים →
   המספרים → הנכסים → החסמים → הנכונות
3. **Gate** — אחרי השאלון, לפני הדוח. שם, עסק, טלפון, אינסטגרם → נשלח ל-CRM
4. **הדוח** — 14 מקטעים + CTA לפגישה

## הגדרות — `CFG` בראש ה-`<script>` ב-index.html

| שדה | מה זה |
|---|---|
| `CRM_URL` | endpoint הלידים. כבר מחובר ל-CRM הקיים |
| `SHEET_URL` | Apps Script `/exec` — גיבוי לגוגל שיטס. אופציונלי |
| `FUNNEL` | שם הפאנל ב-CRM. כרגע `strategy-engine` |
| `AI_URL` | כתובת ה-proxy של Gemini. **ריק = מנוע כללים בלבד, האתר עובד מלא** |
| `MEETING` | לינק קביעת פגישה. ריק → נופל לוואטסאפ |
| `WHATSAPP` | **חובה להחליף** — כרגע `972500000000` |
| `SIGN` | שורת חתימה בפוטר |

הליד שנשלח ל-CRM כולל שדה `notes` עם תמצית מוכנה לפגישה: ציון, מודל,
מחיר ממוצע, פער הכנסה, שעות פנויות, חסם, כאב ובידול — כדי להיכנס לשיחה מוכן.

## שכבת ה-AI (אופציונלי)

מנוע הכללים מייצר דוח שלם לבד. ה-proxy מוסיף שני דברים שרק ניסוח אנושי
פותר: **משפט מיצוב אחד מלוטש** ו**3 רעיונות תוכן** שנכתבו לעסק הזה בלבד.

הוא רץ *אחרי* שהדוח כבר מוצג ומחליף את הטקסט בהחלקה. אם הוא נופל, איטי
או לא מוגדר — המשתמש לא מרגיש כלום ומקבל את גרסת הכללים.

```bash
cd ai-proxy && npm install
```

להריץ עם `ANTHROPIC_API_KEY` בסביבה, ואז להכניס את הכתובת ל-`CFG.AI_URL`.
**מנוע: Google Gemini.** השרת שואל את ה-API אילו מודלים זמינים ובוחר את
הטוב ביותר לבד — כך שהוא לא נשבר כשגוגל מחליפה שמות מודלים.
אפשר לכפות מודל דרך `GEMINI_MODEL`.
